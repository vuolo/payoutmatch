# payoutmatch landing

Public landing page and waitlist for payoutmatch, served at
[https://vuolo.github.io/payoutmatch/](https://vuolo.github.io/payoutmatch/).

This repository contains only the static site (HTML, CSS, and JavaScript).
It does not include the product source code or any API keys.

The on-page demo uses labeled example (mock) data, not a customer account.
Waitlist submissions are delivered by [Formsubmit](https://formsubmit.co) to
the payoutmatch inbox (`vuolo+payoutmatch@mail.grokbot.com`).
